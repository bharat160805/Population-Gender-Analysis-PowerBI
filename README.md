# 👥 Population Gender Analysis Dashboard — Power BI

## 📌 Project Overview

This project is an interactive **Population Gender Analysis Dashboard developed using Microsoft Power BI**.

The dashboard analyzes population data with a focus on **Male and Female population**, providing interactive visualizations and KPIs to understand population distribution and demographic patterns.

The Power BI report contains **two dashboard pages with different visual styles**, allowing the same population data to be explored from different perspectives.

---

## 🎯 Project Objective

The main objective of this project is to transform raw population data into meaningful and interactive visualizations that help users:

* Analyze total population
* Compare male and female populations
* Understand gender-wise population distribution
* Analyze population across different regions/categories
* Identify demographic patterns and trends
* Present data in an easy-to-understand dashboard

## 📊 Dashboard Pages

### Page 1 — Population Overview

The first page provides an overall view of the population data.

It includes visualizations and KPIs related to:

* Total Population
* Male Population
* Female Population
* Male vs Female comparison
* Population distribution
* Regional/category-wise analysis
* Interactive filters and slicers

### Page 2 — Detailed Population Analysis

The second page uses a **different visual style** and provides a more detailed analysis of the population data.

It focuses on:

* Male population analysis
* Female population analysis
* Gender comparison
* Population distribution
* Regional/category-wise comparison
* Demographic patterns
* Interactive visualizations
